UPDATE - External Theme Filter

Estas configs agora incluem:

Filter External By Theme: on
Theme Keywords: ...

Quando importadas no WISP atualizado, o crawler tenta validar dominios externos pelas metatags do site (title, description, keywords, og:title, og:description) antes de listar/exportar.
As palavras de Theme Keywords foram preenchidas com base em Directory Keywords de cada config.
